# GDTCR

GDTCR benchmarks generation and ranking of recorded human gamma/delta TCR CDR3
pairs from one input chain. It includes the original sequence exports, cleaned
inputs, fixed data splits, executed source snapshots, training/evaluation
commands and the BMC Bioinformatics revision's numerical results.

Scores measure recovery of **recorded pairs**. Unrecorded combinations are not
validated biological negatives, and a generated CDR3 is not evidence of receptor
expression, antigen recognition or function.

## Start here

Python 3.10 is the tested Python version. Basic data verification and cleaning use
only the Python standard library:

```bash
git clone https://github.com/he2238751697-afk/GDTCR.git
cd GDTCR
python scripts/reproduce.py verify
python scripts/reproduce.py rebuild-processed --output ../GDTCR-cleaned
```

The second command reads all 43 original input files and checks that the three
newly generated files have the exact recorded SHA256s. It refuses an existing
output directory. Expected counts are 9,068 pairs, 194,887 gamma CDR3s and
1,262,692 delta CDR3s. Historical `light_chain.txt` / `heavy_chain.txt` filenames
mean gamma / delta, respectively.

For model training and analysis, create a separate environment:

```bash
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install -r configs/completion_v2/requirements-lock.txt
OMP_NUM_THREADS=2 PYTHONPATH=src:. python -B -m unittest discover -s tests -v
```

The pinned environment uses PyTorch 2.7.1 with CUDA 12.6. A CUDA GPU is required
for the original training commands. The CPU tests and cleaning do not train the
reported models. See [the reproduction guide](REPRODUCIBILITY.md) for an isolated
run workspace, checkpoint downloads, original task selection and audit commands.

## Included material

| Location | Contents |
| --- | --- |
| `data/raw/` | 43 byte-identical original downloaded exports, about 85 MB |
| `data/processed/` | Three cleaned, deduplicated sequence/pair files |
| `data/provenance/` | File hashes, pair observations and sequence/source lineage |
| `data/splits/` | Original pretraining, primary, directional, source and revision splits |
| `src/`, `scripts/`, `tests/` | Model implementation, analysis and regression checks |
| `configs/` | Unmodified historical experiment manifests and environment pins |
| `reproducibility/` | Release inventory, 600-task index, frozen code and reference inputs |
| `paper/` | Manuscript sources, protocols, figures, numerical tables and data/model cards |

Four inherited pretraining checkpoints are distributed as a separate GitHub
Release asset, with their original paths and SHA256s. They are dependencies of
the downstream experiments; they are not included as Git blobs. The complete
original primary evidence is compressed in `reproducibility/reference/` and can
be restored byte for byte. Newly trained downstream models and full free-draw
arrays must be regenerated by the task manifests; this repository does not claim
to contain every historical training output.

## Scientific status

The original benchmark has 557 completed manifest tasks. The BMC revision adds
43 diagnostic tasks: 12 generator fits, 4 ranker fits, 16 free evaluations and 11
nearest-input baseline tasks. Original primary evidence is preserved with SHA256
`5badb3b9b8ead02c57afeb5f578f85f3a5e343bad9714fb7daa08f48342b2f3b`.
The diagnostics do not replace the primary endpoints. Original fitting used
A800 GPUs; revision fitting used RTX 3090 GPUs. Bitwise reproducibility across
different GPUs is not assumed.

The primary results show lower NLL with pretraining and conditioning, sparse
free partner recovery and no established primary reranking gain. Some exposed
target and source protocols have higher recovery, substantial prior performance
and clustered hits. See `paper/manuscript_bmc.tex` and `paper/DATA_CARD.md`.

The provided PDFs are ReportLab reading copies. Native LaTeX compilation has
not been verified. Author declarations, ethics determinations, funding and a
persistent archive DOI remain pending; public source availability does not
resolve those submission items.
